# Trading Journal for Odoo 19

A professional trade journal and performance tracker for Odoo 19. Record intraday trades, review daily and monthly results, monitor balances, and analyze performance from a dedicated dashboard.

## Main features

- **Trade Journal** — record long/short trades, prices, quantities, currency and notes.
- **Automatic Profit/Loss** — calculate trade results from the recorded trade values.
- **Daily Summaries** — opening balance, closing balance, daily P/L, trade count and win/loss statistics.
- **Monthly Summaries** — aggregate performance across trading days.
- **Interactive Dashboard** — KPIs, equity curve, monthly performance, top symbols, streaks and recent trades.
- **Date Filters** — This Month, Last 3 Months, Year to Date, All Time and Custom Date.
- **Trader Security** — trader-level access plus Trading Supervisor access.
- **Odoo-native** — no broker integration or external API is required.

## Menu structure

After installation, the application provides:

- Dashboard
- Trades
- Daily Summaries
- Monthly Summaries
- Monthly Reports

## Requirements

- Odoo 19.0
- Dependencies: `base`, `mail`, `web`

## Installation

1. Copy the `grow_intraday_trading` folder into an Odoo addons path.
2. Restart the Odoo server.
3. Update the Apps list.
4. Search for **Trading Journal**.
5. Install the module.

## Typical workflow

1. Enter a trade from **Trading → Trades**.
2. Review the calculated trade result.
3. Review the related daily performance.
4. Review monthly aggregation.
5. Use the Dashboard to analyze the selected period.

## Important

This module is a trading journal and performance tracker. It does **not** execute trades, connect to a broker, generate trading signals, or provide investment advice.
